# Apple RU Store — редизайн интернет-магазина

Статический сайт магазина техники Apple в Ростове-на-Дону: главная с каталогом, карточка товара, контакты. Без сборки и зависимостей — открывается как обычные файлы.

Источник данных: страница магазина https://apple-rustore.clients.site (каталог, акции, условия, отзывы, контакты). Цены и состав каталога на 10.10.2026.

## Что внутри

- `index.html` — главная: разделы, акции, факты, каталог с поиском и фильтрами, условия покупки, отзывы, FAQ, контакты.
- `product.html` — карточка товара (`product.html?m=<модель>&v=<вариант>`): галерея, выбор памяти и цвета, цена, характеристики, кнопки связи.
- `catalog.js` — все товары (38 моделей, 88 вариантов).
- `app.js`, `style.css` — логика и оформление.

## Что сознательно не показывается

Наличие, скидки, рейтинги и сроки гарантии, которых нет в данных магазина. Вместо наличия — кнопка «Уточнить наличие» (открывает WhatsApp с названием модели). Статус «Авторизованный реселлер Apple» нигде не заявлен.

## Как обновить каталог

Редактируйте `catalog.js`. У каждой модели в `models` есть список вариантов `v`:

- `i` — код позиции в каталоге магазина;
- `s` — память или размер, `c` — цвет;
- `p` — цена в рублях (`null`, если цена не подтверждена);
- `im` — ключ фото;
- `n: 1` — отметка магазина «устройство без приложения RuStore»;
- `u` — ссылка на объявление Авито (необязательно).

После правки цен обновите дату `updated` в начале файла — она показывается на сайте.

## Авито

Публичного API для чтения объявлений нет, а страница продавца закрыта проверкой от автоматических запросов, поэтому автосинхронизации нет — и сайт её не изображает. Чтобы привязать объявление, впишите его адрес в поле `u` нужного варианта (или модели): в карточке появится кнопка «Объявление на Авито». Пока поля нет, кнопка ведёт на каталог магазина: https://www.avito.ru/brands/apple_ru_store/all

## Фото

Фото подключаются с серверов Яндекса из каталога магазина. Для нескольких цветов одной модели магазин использует одно и то же фото.

## Публикация

Подходит любой статический хостинг, например GitHub Pages: включить Pages для ветки `main`, корень репозитория.
